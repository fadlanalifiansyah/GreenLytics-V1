Nama Proyek: GreenLytics
Versi: 1.0.0
Tanggal: 2026-05-06

Deskripsi:
GreenLytics adalah aplikasi pelacak jejak karbon (carbon footprint tracker) berbasis Android. Aplikasi ini dirancang untuk membantu pengguna memantau, memahami, dan mengurangi emisi karbon harian mereka secara praktis. Perhitungan emisi dalam aplikasi ini dikalibrasi menggunakan standar GHG Protocol dan Grid Emission Factor (GEF) khusus untuk Indonesia. Proyek ini mengedepankan desain antarmuka yang modern serta sistem gamifikasi untuk mendorong kebiasaan yang lebih ramah lingkungan.

Cara Penggunaan:
Aplikasi ini didistribusikan secara langsung melalui file mentahan Android (.apk). Berikut adalah langkah-langkah instalasinya:
1. Unduh file GreenLytics.apk melalui tautan Google Drive berikut:
   [Download Aplikasi GreenLytics Disini](https://drive.google.com/file/d/1aX8A4Gt_6NBRdkGMcxl0hJurXRqLLgPw/view?usp=sharing)
2. Setelah proses pengunduhan selesai, buka folder "Downloads" atau "Unduhan" melalui aplikasi File Manager di perangkat Android Anda, lalu cari dan ketuk file APK tersebut.
3. Jika perangkat memunculkan peringatan keamanan, ketuk opsi "Pengaturan" pada kotak dialog yang muncul, lalu aktifkan izin "Install from Unknown Sources" (Instal dari sumber tidak dikenal) untuk browser atau File Manager yang Anda gunakan.
4. Ketuk tombol Instal dan tunggu hingga proses pemasangan aplikasi selesai.
5. Buka aplikasi GreenLytics. Saat pertama kali dibuka, pastikan Anda memberikan izin akses lokasi (Location Permission) menjadi "While using the app" yang diminta oleh sistem agar fitur pemetaan berfungsi dengan baik.

Fitur:
- Dashboard Interaktif: Memantau total emisi karbon harian yang dibagi menjadi beberapa kategori pengeluaran (Transportasi, Listrik, Makanan, Belanja, dan Sampah).
- Tren Mingguan Dinamis: Menampilkan grafik visualisasi emisi yang terstruktur dari hari Senin hingga Minggu untuk mengevaluasi efektivitas pengguna.
- Sistem Gamifikasi: Menghitung rekor hari berturut-turut (streak) dalam memasukkan data emisi dan memberikan pencapaian berupa Badge (Pemula Hijau, Pejuang Iklim, Eco Champion, Guardian Bumi).
- Pemetaan Data Geospasial: Mengumpulkan data koordinat aktivitas pengguna secara aman untuk membantu pemerintah atau instansi terkait mengisi celah data (data gaps) emisi karbon di lapangan.

Pemecahan Masalah:
- Warna Antarmuka (UI) Berantakan atau Teks Tidak Terbaca: Matikan mode gelap (Dark Mode) pada perangkat Anda. Aplikasi ini belum mendukung Dark Mode secara penuh.
- Peta atau Data Lokasi Tidak Akurat: Pastikan fitur GPS di perangkat Anda dalam keadaan aktif dan aplikasi GreenLytics telah diberikan izin lokasi (Minimal "While using the app").
- Autentikasi atau Data Tidak Sinkron: Pastikan perangkat terhubung ke jaringan internet yang stabil, karena beberapa fitur utama terhubung dengan database cloud (Firebase).

Catatan:
- PERHATIAN PENTING: Jangan menggunakan aplikasi GreenLytics dalam keadaan perangkat mode gelap (Dark Mode). Desain UI dan palet warna dioptimalkan secara khusus untuk mode terang (Light Mode). Penggunaan mode gelap akan membuat warna elemen bertabrakan dan mengurangi kenyamanan visual secara drastis.
- Data identitas dan koordinat pengguna disimpan dengan aman dan murni difokuskan untuk analisis makro jejak karbon lingkungan, bukan untuk melacak privasi pergerakan individu.
